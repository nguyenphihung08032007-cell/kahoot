Đưa Web Lên Link Công Khai

Ứng dụng đã tích hợp sẵn máy chủ đồng bộ thời gian thực qua Internet (4G/Wi-Fi). Để học sinh dùng điện thoại quét mã QR trực tiếp, bạn chỉ cần xuất bản file HTML thành một đường link công khai theo 3 bước:

1
Tải file HTML độc lập về máy tính

File chứa trọn vẹn 50 câu hỏi Vectơ Toán 10, KaTeX, âm thanh và kết nối đa thiết bị.

2
Đẩy lên GitHub Pages hoặc Tiiny.host

Tải file index.html lên repository GitHub của bạn và bật Settings → Pages → Branch: main (để trống ô Custom domain) để nhận link https://...github.io/kahoot/.

3
Mở link đó & Tạo phòng quét mã QR

Khi mở trực tiếp từ link https://..., mã QR sẽ tự động nhận diện đường dẫn chuẩn để điện thoại học sinh quét và tham gia ngay lập tức!
